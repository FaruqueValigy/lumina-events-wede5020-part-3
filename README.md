# Project Overview

Lumina Events is a fictional event planning company created for the WEDE5020 Portfolio of Evidence. The website promotes the company's event planning services, provides information about the business, showcases previous events, and allows potential clients to submit booking enquiries.

---

# Website Goals

The website aims to:

- Promote Lumina Events and its services.
- Provide information about the company.
- Showcase previous events through a portfolio.
- Allow customers to submit booking enquiries.
- Provide contact information for potential clients.

---

# Website Features

- Multi-page HTML5 website
- Responsive website structure (to be completed in later parts)
- Homepage
- About page
- Services page
- Portfolio page
- Plan Your Event (Booking) page
- Contact page
- Navigation menu on every page
- Booking enquiry form
- Semantic HTML5 structure
