# Project Overview

Lumina Events is a fictional event planning company created for the WEDE5020 Portfolio of Evidence. The website promotes the company's event planning services, provides information about the business, showcases previous events, and allows potential clients to submit booking enquiries.

---

# Website Goals

The website aims to:

- Promote Lumina Events and its services.
- Provide information about the company.
- Showcase previous events through a portfolio.
- Allow customers to submit booking enquiries.
- Provide contact information for potential clients.

---

# Website Features

- Multi-page HTML5 website
- Responsive website structure with desktop and mobile layouts
- Homepage
- About page
- Services page
- Portfolio page
- Plan Your Event (Booking) page
- Contact page
- Navigation menu on every page
- Booking enquiry form
- Semantic HTML5 structure

```

├── index.html

├── contact.html

├── css/
│   └── style.css

├── js/
│   └── script.js

├── images/
│   └── README.md

├── docs/
│   ├── ST10520864-task-1 WEDE5020.pdf
│   ├── ST10520864-WEDE5020-Part-2-evidence.docx
│   ├── part-2-evidence-matrix.md
│   └── part-2-testing-log.md

└── README.md
```

HTML pages remain at the project root so their existing relative links to the
shared `css/`, `js/`, and `images/` folders continue to work. Coursework
documentation is kept separately in `docs/`.

The portfolio page uses three self-contained SVG illustrations in `images/`.
They can be replaced with approved photographs later without changing the
gallery interaction or accessibility text.

Part 2 evidence is recorded in `docs/ST10520864-WEDE5020-Part-2-evidence.docx`,
with the supporting matrix and testing log in the same `docs/` folder. The
official Part 2 rubric/template was not included in the supplied project, so
the evidence matrix records verified implementation against the Part 1
proposal and identifies anything that still needs lecturer-provided marking
terminology.
